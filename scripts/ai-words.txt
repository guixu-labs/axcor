# AI 常用生硬表达黑名单。每行一条：词 => 建议替换
# 词按子串匹配；暂不支持英文条目（纯英文词会报配置错误）。
# `!` 前缀行是豁免路径（fnmatch 匹配仓库相对路径，`*` 可跨目录）。
# 建议文本不要出现词表中的其他词，否则按建议改写后仍会被打回。
# 注意：门禁、对齐、闭环、落地等词在仓库中仍有正当用法，不要收录；
# 单字文言词拆成具体形态收录（如「恒为」而非「恒」），避免误伤
# 「恒等式」「恰当」等正常复合词。
